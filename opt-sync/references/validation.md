# 正确性、性能验收与按生命周期回退

实施前约定项目数值容差与测量口径。分别报告 **配置/开关已开启、运行时优化路径真实命中、数值与功能等价、端到端稳态提速**。

## 1. 数值与功能正确性

在相同权重、输入、随机态和编译/分布式配置下对照前后结果。检查前向输出、loss、反向梯度、输出结构与 dtype，并覆盖 NaN/Inf 行为。

- **P1 标量留设备**。核对零维张量与 Python 标量的 dtype 提升、精度和梯度契约。设备端选择覆盖原分支跳过的计算和被掩蔽位置的 NaN/Inf。
- **P2 元数据与缓存**。覆盖缓存冷/热、容量上限、设备/dtype 或模型配置变化、纯文本/图像/视频，以及拦截未命中。由形状推导的计数需要覆盖原布局和特殊帧数边界。
- **P3 动态形状与去重**。覆盖全 0、全 1、单元素、空结果与反向梯度。确认索引唯一性及下游次序，并记录残留的动态算子。
- **P4 Attention 路径**。覆盖右 padding、左 padding、含洞 mask、cache/decode 与后端不匹配。确认前提未满足时原路径命中。按实际关注的有效 token、padding 输出和反向梯度验等价，并记录守卫和回退的同步。
- **P5 延迟指标**。分别验证梯度累积为 1 与大于 1。检查 `.detach()` 只用于指标支路、生产端/消费端成组启停以及未消费张量及时释放。对齐日志步号和数值，验证正常收尾及 checkpoint 边界的最后一笔指标得到处理。
- **P6 显式同步**。覆盖有无分布式、日志/GC 步与 checkpoint 保存恢复。需要保证 NaN/Inf、异常或文件可见性的同步标为「正确性保护（非提速）」。
- **P7 CPU 求解**。检查空匹配、并列代价、结果顺序、索引 dtype/device 与最终分配。用 Trace 核对 D2H 和 H2D 次数及等待位置。
- **P8 异步拷贝**。核对 CPU 侧 pinned 状态、拷贝结束前的缓冲区生命周期、跨流数据依赖与分配器保护。CPU 读取 D2H 结果前验证拷贝完成。用多轮高复用输入验证读回正确性及首末步。

对受限的 `inv_ex` 实现，验证可逆和奇异输入及异常契约。若沿用同步错误检查，将它单列为正确性保护。若依赖上游保证可逆，验证该保证涵盖目标数据。保留 `info` 时，明确谁在何时处理错误及是否引入等待。

## 2. 分布式与 Checkpoint 一致性

- **集合契约**。各 rank 的参与者、调用顺序、shape 与 dtype 必须兼容。允许一致地合并归约。核对键序、逐元素值、权重和缩放语义，检查某个 rank 缺指标时的行为。
- **延迟步号**。各 rank 使用同一步指标。若启用 side stream，核对集合依赖、消费事件及源缓冲区回收。
- **Checkpoint 往返**。核对状态格式和已保存优化器状态。触及训练循环或 step 计数时，比较保存、加载、续训一步与基线，并验证关闭优化后的恢复路径。

## 3. 性能验收

- **运行时命中**。用调用计数、分支标记或 Trace 证明实际选择的路径，分别记录快路径和必要回退的次数。
- **同步与 GPU 空闲**。按 [profiling.md](profiling.md) 或 `trace-triage` 的口径，比较目标事件的次数和等待时长以及对应的 GPU 空闲。记录等待从一处移动到另一处、计算增加或传输次数下降但关键路径不变的情况。
- **稳态墙钟**。独立于 Profiler 测端到端，跳过预热并汇报样本数、中位数、离散度。用同一可归因的配置比较，强耦合改动以组为单位消融。
- **回归或无收益**。记录证据并按生命周期回退。保留正确性所需的同步与回退分支。

## 4. 回退与离线边界

- 局部开关无持久状态时，关闭后验证原路径。
- 跨步指标先按消费契约处理或排空未完成拷贝，再清理缓存和缓冲区。位置编码缓存按所有权清除，必要时重建持有对象。
- 已安装类/模块包装用可用的卸载路径恢复。影响已构造模型、优化器或编译图时，只重建受影响对象或清理和重新捕获对应编译缓存。
- 环境变量、框架配置或全局安装钩子若在进程初始化时锁定，重启以恢复初始状态，按其影响范围重建对象。
- 缺设备或运行依赖时，完成可行的静态接入与 CPU/mock 边界测试，将设备路径、设备数值和端到端性能分别标为「未验证」。
