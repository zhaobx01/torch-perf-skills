# TurboPhysAI 跨模型同步消除证据

- 汇总分支 [zhaobx01/TurboPhysAI corpus/all-models](https://github.com/zhaobx01/TurboPhysAI/tree/corpus/all-models)，本文件全部 After 行使用快照 `796d3f6bce998d91af9d336f506a769b2bdde927`。
- 覆盖 16 个模型、相关框架基线及 Cosmos3 独立补丁。下文的 Before 路径相对于本地语料 `baselines/`，以关键符号定位。证据来自静态源码，性能、命中和设备等价需在目标环境验收。若引用作者的次数或收益，一律标「来源自述，未复测」。
- 「已核实改造案例」表示 Before 和 After 对照完成。「实现参考，基线待核实」表示当前本地基线不足。「受限/单模型参考」和「版本兼容性待核对」可与两者并列。 [模式与适用条件](patterns.md)

## 3. 受限案例、正确性保护与排除项

- **BEVFusion 逆矩阵错误检查（已核实改造案例，受限/单模型参考，版本兼容性待核对）**。Before `models/bevfusion/mmdet3d/models/vtransforms/base.py` 的 `BaseTransform.get_geometry` 使用 `torch.inverse`。After [depth.py](https://github.com/zhaobx01/TurboPhysAI/blob/corpus/all-models/turbo_physai/optimizations/models/bevfusion/depth.py) 的 `dense_base_transform_get_geometry` 和 `base_transform_get_geometry` 使用 `torch.linalg.inv_ex(check_errors=False)[0]`，丢弃 `info`。目标项目需证明上游矩阵可逆，或保留并按契约处理 `info`。奇异矩阵或错误语义需保留时，使用带错误检查的原路径。这个回退属于「正确性保护（非提速）」，需单测可逆、奇异两支。
- **BEVFormer 拷贝/预取与回退（受限参考）**。Before `models/bevformer/projects/mmdet3d_plugin/bevformer/modules/spatial_cross_attention.py` 的 `SpatialCrossAttention.forward` 按实际有效索引构造变长结果。After [geometry_sca.py](https://github.com/zhaobx01/TurboPhysAI/blob/corpus/all-models/turbo_physai/optimizations/models/bevformer/geometry_sca.py) 的 `encoder_forward` 使用 `_prefetched_sca_inputs`。未命中时分支仍执行 `int(index_lengths.max().item())`。验证/测试 loader 必须核对实际预取命中，流水线改造交数据管线。
- **Cosmos3 checkpoint 与 MapTRv2 恢复（正确性保护）**。[Cosmos3 补丁](https://github.com/zhaobx01/TurboPhysAI/blob/corpus/all-models/model_examples/Cosmos3/cosmos-framework.patch) 的 `checkpoint/dcp.py` 在预分配失败状态传播中调用 `bool(failed.item())`。已有 staging 流完成等待保证保存读到完整数据，加载阶段有跨 rank 同步。MapTRv2 [optimizer.py](https://github.com/zhaobx01/TurboPhysAI/blob/corpus/all-models/turbo_physai/optimizations/models/maptrv2/optimizer.py) 的加载状态校验为一次性读回。
- **已搜但未发现独立步内 D2H 改造**。OpenWAM 的 VAE/pointwise 路径、OpenPI、FlashOCC 和 DreamZero 主要命中其他领域。DreamZero [skip_unused_vae.py](https://github.com/zhaobx01/TurboPhysAI/blob/corpus/all-models/turbo_physai/optimizations/models/dreamzero/skip_unused_vae.py) 的噪声均值只在首次日志路径计算。Sparse4D [instance_bank.py](https://github.com/zhaobx01/TurboPhysAI/blob/corpus/all-models/turbo_physai/optimizations/models/sparse4d/instance_bank.py) 有单步小标量上传变体，其主要改造另见布局/算子；`channels_last.py` 的 feature-map 元数据缓存随布局交接。C++/HIP 扩展内部同步超出本轮 Python 静态检索。
- **邻近方向**。DataLoader 的 batch 级 H2D 预取归数据管线。`max_seqlen` 分桶、定长 padding 和 LeRobot `AsyncCompile.triton` 归编译专项。ZeRO/FSDP 集合调度归通信专项。FA2 的设备 kernel 性能、主机读回和编译捕获按主要症状选择 Skill。
