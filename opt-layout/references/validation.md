# 正确性、性能和失败回退

先约定精度、任务指标容差与性能目标；不要用任意固定容差替代项目要求。准备相同权重、输入、模式、随机状态和后端配置的独立基线与候选，避免同一模型原地转换污染基线。

## 数值、布局命中与契约覆盖

- **边界布局真命中核对**：核对布局真正落到每个目标卷积和自定义算子的输入上，而不仅在入口处。在关键边界记录 `shape`、`stride()` 与 `is_contiguous(memory_format=...)`，并用 profiler 确认目标卷积与自定义/融合算子（DCN、GridSampler、融合 3D conv 等）实际走了 NHWC/NDHWC 路径而非静默回退。配置里出现开关或 ROCm 变量不等于路径命中；名为 `channels_last` 的参数可能只是逻辑轴排列，切勿混淆。
- **典型与退化 shape**：覆盖 `N=1`、`C=1`、`T=1`、`H=W=1`、非方形/动态输入及真实非连续输入；确认非图像/非体积的 4D/5D 张量（token、相机维、索引、元数据）未被盲改。核对 `view`/`reshape`、`rearrange` 5D↔4D 切换、alias、原地更新、缓存生命周期与输出协议，检查 NaN/Inf。
- **3D 非对称反向与训练状态**：
  - 若评估受限的 L3，比较前向输出、`weight.grad`、`bias.grad` 及前反向各自耗时，计入每次调用的布局转换。构造需要输入梯度的输入，确认该参考实现明确报错。移植前核对目标卷积的参数与梯度契约。
  - 训练场景用相同初始参数、优化器、AMP 和随机状态对比 forward、loss、输入/参数梯度、多步更新与 buffer。
- **Checkpoint 与优化器状态往返**：核对保存前是否需要连续化 `optimizer.state_dict()` 中的状态张量（L4）。执行"开启保存 → 关闭加载续训"与"关闭保存 → 开启加载续训"双向往返。检查各路径的状态 stride 符合预期，数值与下一步结果满足容差。
- **Eager、Compile 与分布式**：分开检查 eager 与实际使用的 `torch.compile` 下的功能、stride guards、重编译次数、首轮与稳态；DDP/FSDP/DeepSpeed 下确认各 rank 路径、参数引用与梯度通信一致。
- **成组启停与异常路径**：ACT 同组验证首层与 pool 标记、未标记回退、带标记的非法输入、保存及双向恢复。Sparse4D 覆盖缓存未命中、命中、shape 或设备变化、逆向打包，恢复时一起撤销构造、特征提取和打包包装。BEVFusion 分别验证权重开关和相机入口环境变量的生效情况。为守住数值或接口契约而走的参考路径标为「正确性保护（非提速）」。

## 性能验收

- **四层结论拆分**：`配置/开关已开启` ≠ `布局实际落到卷积/算子输入` ≠ `数值与状态等价` ≠ `含转换成本的端到端稳态提速`。
- **变量隔离消融**：布局代码开关、`PYTORCH_MIOPEN_SUGGEST_NHWC/NDHWC`、`torch.compile`/`TORCHINDUCTOR_LAYOUT_OPTIMIZATION`、`MIOPEN_FIND_MODE` 与精度开关必须分开消融；固定并记录 FindDb/PerfDb 状态与原环境变量默认值（unset 不一定等于关闭），不把缓存命中差异误认作布局收益。
- **组合改动归因**：DreamZero DiT 的布局与 activation checkpointing 在语料中同组。用拆分后的单项对照量化布局影响。只能对比整组时，记录改动组合并报告整组吞吐和显存差异。
- **统计口径**：预热并记录预热步数、测量前同步设备（ROCm 上 PyTorch 通常仍用 `torch.cuda.synchronize()`），多次测量报告中位数与离散范围；分别报告初始化/编译/搜索冷启动与稳态，分别看包含输入转换的端到端耗时与局部子图耗时，同时记录峰值显存（多 rank 时记录最慢 rank）。通过 profiler 排查隐式复制与布局传播。
- **诚实交付**：汇报版本、硬件、输入、命令、开关、容差、结果、分布与未验证项。缺少目标设备或依赖时仅完成静态接入与 CPU/边界单测，明确标为"设备数值与性能未验证"，不把源码注释或配置文件当作实测结论。

## 回退（按生命周期界定）

- **纯调用期开关**（仅控制输入临时转换、不修改已存在权重布局且无进程级变量/缓存残留）：关闭开关即可直接恢复原路径，无需重启进程。
- **模块与进程状态**：仅增加模块输入 hook 时，移除其句柄并确认调用路径恢复。已经转换权重或改变参数引用时，重建受影响的模型与优化器并检查恢复状态。编译或算子缓存依赖布局时重建对应包装或缓存，进程级变量和难以隔离的全局状态用新进程对照。联动包装与缓存按组回退。
