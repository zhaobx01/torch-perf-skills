# 运行时环境变量分轨验收与回退

在独立新进程中对照基线与候选。按四层分别交付 **配置生效 ≠ 路径命中 ≠ 正确性与数值通过 ≠ 端到端稳态提速**。

## 1. 对照实验

1. **锁定基线。** 记录目标硬件、库构建、代表性 workload、权重、输入与相关变量的实际值或未设置状态。核对来源、继承、CLI 覆盖以及程序入口内的 preset 或条件默认值。
2. **隔离改动。** 优先一次改一个变量。涉及 topology、精度 hook、生成产物或缓存的强依赖，先说明分组理由，再成组设置与回退。代码与启动配置联动时由对应领域专项主导代码路径。
3. **区分启动成本与稳态。** 独立记录首次搜索、编译、建环或缓存预热。以一致的预热和采样口径比较基线与候选，稳态测速关闭 Profiler。另记样本数和离散度。
4. **缺目标 GPU。** 按本轮授权做静态接入、配置合成或可执行的 CPU/mock 检查。目标设备路径、数值与性能分别标为未验证。

## 2. 分轨验收

| 类别 | 路径命中证据 | 正确性与副作用 | 性能 |
| --- | --- | --- | --- |
| **R1 精度与数学库** | 查看能区分数学模式的后端日志、生成代码或已核对的设备 kernel，并确认实际执行了它。 | 按 §3 验证训练或推理容差，查敏感路径。 | 稳态 step time、延迟或吞吐。 |
| **R2 MIOpen 搜索与布局** | 核对实际 Find 模式、数据库命中、卷积算法和输入 stride，覆盖 shape 变化。 | 输出与数值容差、布局转换和峰值显存。 | 首次和重复搜索成本、预热后的稳态耗时。 |
| **R3 队列、PCIe 与显存** | 分配器用生效日志、内存快照或统计；队列或 PCIe 用目标运行时日志、可用队列/传输计数或受控 stream 对照。 | OOM、allocator retries、峰值、碎片及捕获兼容性。 | 稳态吞吐、步时长尾和显存余量。 |
| **R4 通信与 CPU 线程** | 核对 NCCL/RCCL 初始化、实际算法和拓扑，各 rank 的线程数和 CPU 分配。 | 核对 rank 映射、代表性多卡正确性、超时与结束行为。检查 DataLoader worker 或后台监控的相关契约。 | 多卡吞吐、集合暴露和 CPU 利用率。 |
| **R5 Inductor/Triton 与缓存** | 核对实际生成配置、缓存路径与命中日志，以及 autotune 后端。 | 编译、缓存隔离、共享内存容量与多进程复用；影响数学语义时执行 §3。 | 首编与复用分开，另报稳态耗时和必要的主机内存峰值。 |

## 3. 涉数值改动的验收

沿用项目容差，关键阈值缺失时先约定。主动改变数学精度时用约定容差；声明保留原契约时核对功能与数值等价。收到超界结果后按 §4 恢复基线，保留复现输入或步号。

- **训练**：固定初始权重、输入和随机条件做单步输出、loss、梯度与 NaN/Inf 对照。短跑对照样本顺序、学习率和优化器，比较 loss 曲线、梯度范数和代表性任务指标。长跑或最终评测缺失时单列。
- **推理**：固定权重、预处理与解码设置，覆盖常见 batch/长度/分辨率及敏感边界，核对输出 dtype、shape、误差、NaN/Inf 和下游指标。状态化模型同时核对连续请求和缓存重置。

## 4. 按生命周期回退

| 情况 | 复验动作 |
| --- | --- |
| **启动环境** | 恢复实际基线值或未设置状态，覆盖 shell、配方、CLI 和后加载 preset。启动新进程确认恢复后的设值、执行路径和指标。 |
| **MIOpen 搜索或精度** | 配套恢复变量与对应的 FindDb/PerfDb 状态。若对照受数据库污染，切换已核实的独立环境或路径，新进程复验。 |
| **编译与缓存** | 恢复基线 tag 或独立目录，核对缓存作用域和实际产物。涉及 hook 与编译代码时成组还原。 |
| **可疑保护或拓扑绑定** | 先恢复已知可用配置，复验原故障场景与代表性负载。对集群拓扑核对真实机器、卡数及 rank 映射，按目标构建确认配置受支持。 |
