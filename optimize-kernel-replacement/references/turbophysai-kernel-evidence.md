## 二、按机制精选代表要点

### 1. 融合优化器：原生 AdamW、Apex FusedAdam 与 Muon
- **标准 `AdamW(fused=True)`（同质合并）**：OpenVLA（`setdefault`）、BEVFormer（校验 `type=="AdamW"` 后开启）、DiT4DiT（直接传 `fused=True`）、OpenWAM（开关 `fused_adamw` 默认关；注释「来源自述，未复测」："One fused kernel per tensor group instead of seven foreach passes ... same AdamW update, rounding may differ slightly"）。**代表边界处理**：[openpi/fused_adamw.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/openpi/fused_adamw.py) 先将参数生成器 materialize 一次，再逐组校验未显式传 `fused`/`foreach`/`differentiable` 且全部为 CUDA 浮点后才注入 `fused=True`。
- **Apex `FusedAdam`（代表契约与反例）**：
  - [maptrv2/optimizer.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/maptrv2/optimizer.py) 给出完整适配范本：AST 检查 `FusedAdam.step` 确认 group-step 契约、拒绝不支持选项与同组部分 `grad=None` 导致的步数分叉、全空组不递增 step、并在 `state_dict`/`load_state_dict` 与标准 PyTorch AdamW 双向互转。
  - [groot/optim.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/groot/optim.py) 同检 `FusedAdam` + `multi_tensor_applier.available` + `amp_C.multi_tensor_adam`，并显式排除 DeepSpeed `cpu_offload`/`offload_optimizer`。
  - [lerobot_act/apex_fused_adamw.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/lerobot_act/apex_fused_adamw.py) 补 `group.setdefault("step", 0)`；[sparse4d/fused_adam.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/sparse4d/fused_adam.py) 先导插件再注册 `OPTIMIZERS` 防覆盖（实现参考，基线待核实）。
- **Muon 批量化与多张量 Triton 融合**：基线 `lingbotvla/optim/muon.py` 用固定 chunk=32、逐参数循环做 `lerp_`/`mul_`/`add_`。After 拆为 [muon_fused_kernels.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/lingbot_vla_v2/muon_fused_kernels.py)（int64 指针表按 `data_ptr` 缓存上限 4096 + pinned 异步拷贝 + `is_current_stream_capturing()` 守卫；单张量设 `_FUSE_MIN_ELEMS = 2 << 20`，注释「来源自述，未复测」称小张量 ATen `lerp` 已近带宽上限、融合更慢）与 [muon_batched_ns.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/lingbot_vla_v2/muon_batched_ns.py)（按 `A=[B,M,M]` bf16 256 MB 预算动态选 chunk ∈ `[32, 128]`，packed gather 布局用 `_pack_kernel` 重排转连续 bf16）。

### 2. FlexAttention 调优与架构守卫模板
- **Head 共享 BlockMask + Tile + TF32 缓存隔离**：基线 `lingbotvla/.../flex_attention.py` 把 3D mask 先 `.expand(-1, num_heads, ...).contiguous()` 再调 `create_mask` 分配稠密 4D mask，且 Q/K/V 转 `float32`。After 通过 [flex_head_shared_mask.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/lingbot_vla_v2/flex_head_shared_mask.py) 直接 `H=1` 广播并删去 `create_mask`（默认 `block_size=64`）；[flex_kernel_options.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/lingbot_vla_v2/flex_kernel_options.py) 合并前反向 tile；[flex_attn_tf32.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/lingbot_vla_v2/flex_attn_tf32.py) hook `get_float32_precision` 返回 `"'tf32'"` 并强制追加 `torch.compiler.config.cache_key_tag` 防 FX graph cache 命中旧 `ieee` 图。
- **Cross-Attention FA2 捷径与架构白名单模板**：[lingbot_va/attention.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/lingbot_va/attention.py) 仅在全部 shape/padding 契约命中时对前 `valid` token 走 `flash_attn_func` 再 pad；[flex_assets/implementation.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/lingbot_va/flex_assets/implementation.py) 用 `ShapeEnv` 符号 guard 严格锁定 `gcnArchName=="gfx936"`、bf16、shape、stride 后才注入 `waves_per_eu=4`/`kpack=2`，并与序列整除性正确性检查 `_guard_sequence_divisibility` 解耦。

### 3. 注意力后端选择、路由优化与冗余裁剪
- **正确性兜底反例**：[groot/replacements.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/groot/replacements.py) 在 HIP 上默认强制 `SDPBackend.MATH`（基线注释「来源自述，未复测」称 DTK/HIP 默认 SDPA 后端在 DiT bf16 反向产 NaN），属正确性回退非提速；[groot/attention.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/groot/attention.py) 将 `AttentionInterface._global_mapping.flash_attention_2` 一并 `torch._dynamo.disable`。
- **Uniform batch 走 dense FA2**：基线 `dreamzero/.../attention.py` 即使 `q_lens`/`k_lens` 为 `None` 也 flatten 并造 `cu_seqlens` 调 `flash_attn_varlen_func`；[dreamzero/attention.py](https://github.com/zhaobx01/TurboPhysAI/blob/796d3f6bce998d91af9d336f506a769b2bdde927/turbo_physai/optimizations/models/dreamzero/attention.py) 在等长且满足 FA2 条件时直调 `flash_attn_func`。
